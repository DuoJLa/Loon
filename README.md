# LoonPlugin

Loon plugins converted from Egern and other proxy formats.

## 插件列表

| 插件 | 说明 | Loon 导入 |
| --- | --- | --- |
| NodeSeek 自动签到 | 捕获 NodeSeek 请求头（Cookie）并按设定时间自动签到，可选择随机或固定 5 鸡腿。 | [Loon 插件](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2FDuoJLa%2FLoonPlugin%2Fmain%2Fnodeseek%2FNodeSeek.plugin) |
| Fuck Telegram Bad IPs | 将 Telegram 客户端的垃圾 IP 映射为优质 IP。 | [Loon 插件](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2FDuoJLa%2FLoonPlugin%2Fmain%2Ftelegram-ip-map%2FFuckTelegramBadIPs.plugin) |
